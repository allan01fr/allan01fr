# 99 · Prévia dos próximos blocos

**Para que serve**
Mostra, em forma de maquete, como deverão ficar as próximas telas: execução de obra, preço com comparação de cotações e ARTs, viabilidade e documentos. Serve para revisar o layout antes de as funções serem construídas.

**Aviso importante**
Esta página é uma maquete visual. Os valores são fictícios, os cálculos são de exemplo e os botões ainda não fazem nada. Não use os números da prévia em proposta nem em estudo para cliente.

**Campos e botões**

| Campo/botão | O que faz | Observação |
|---|---|---|
| Aba "Execução de obra" | Mostra serviços, equipe, cronograma e curva ABC | Valores de exemplo |
| Aba "Preço, comparação e ARTs" | Mostra cotações, preço adotado e ARTs previstas | "Adotar este valor" é ilustrativo |
| Aba "Viabilidade" | Mostra a sensibilidade do VPL à economia anual | Não recalcula nada |
| Aba "Documentos" | Mostra o botão de relatório para o cliente (DOCX) | Botão sem função nesta versão |

**Passo a passo**
1. Abra a página "Prévia dos próximos blocos" pelo menu lateral.
2. Leia o aviso azul no topo: é uma maquete com valores fictícios.
3. Navegue pelas quatro abas e veja se a organização faz sentido para o seu trabalho.
4. Anote o que precisa mudar e envie o retorno antes de a função ser construída.

**Cuidados e limitações**
- Nenhum dado desta página vem do seu orçamento real.
- Campos e botões não gravam nada e não geram arquivos.
- Os textos e os nomes de abas podem mudar quando a função for implementada.
